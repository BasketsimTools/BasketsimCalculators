Basketsim Tools is a free Chrome extension designed to help Basketsim managers make better financial and strategic decisions.

The extension includes four practical calculators, integrated into the following Basketsim menus:

MARKET MENU

Agents Tool
Calculate and estimate agent-related costs to better understand the financial impact of player transfers and transactions.

FINANCES MENU

Sponsors Tool
Estimate sponsorship-related income and compare financial scenarios to support your club's budget planning.

ARENA MENU

Cheerleaders Tool
Calculate the recommended investment in cheerleaders based on your arena's total capacity. Arena capacity is automatically detected from Basketsim and can also be adjusted manually.

Arena Tool
Plan arena expansions, calculate construction costs, estimate construction time and determine recommended seating distribution. Adjust your desired capacity and review the financial requirements before starting construction.

The calculators use formulas originally published by BSGoodies, adapted for convenient use directly within Basketsim.

BSGoodies: https://www.bsgoodies.com/

INSTALLATION INSTRUCTIONS

1. Download the latest Basketsim Tools ZIP file from GitHub.
2. Extract the ZIP file to a folder on your computer.
3. Open Google Chrome.
4. Enter chrome://extensions in the address bar.
5. Enable Developer mode in the upper-right corner.
6. Click Load unpacked.
7. Select the extracted extension folder containing manifest.json.
8. The extension is now installed and ready to use.

HOW TO USE

1. Visit https://www.basketsim.net/ and log in to your account.
2. Open Market to access the Agents Tool.
3. Open Finances to access the Sponsors Tool.
4. Open Arena to access the Cheerleaders Tool and Arena Tool.
5. Enter or adjust the required values.
6. Review the calculated results before making decisions in the game.

Some values may be automatically detected from the Basketsim website, while others can be entered manually.

Basketsim Tools is an independent, community-developed extension and is not officially affiliated with Basketsim or BSGoodies.

All calculations are intended as planning aids. Actual in-game results may vary depending on game mechanics and future updates.
